# Debug Baselines

These files are redacted diagnostic extracts from Starlink debug exports captured on 2026-09-05.

- `2026-09-05-failing-redacted.json` — dish in reboot-loop/failing RF state.
- `2026-09-05-working-redacted.json` — dish after successful firmware recovery and restored Internet service.

Only diagnostically relevant fields are retained. Account identifiers, push tokens, device/client identifiers, MAC addresses, IP details, SSIDs, hostnames, and other unrelated private fields are omitted.

Do not replace these files with raw unredacted exports in the repository. Keep originals private if retained.
